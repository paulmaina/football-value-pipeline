# Market-implied fair price: calibration check

Read-only check, not tuning. Pinnacle CLOSE prices; fit A = 1X2 + O/U 2.5, fit B = 1X2 + O/U 2.5 + main AH. Each line is bet at the matrix fair price on matches where both fits are usable; a correct price returns zero on average. 95% intervals resample whole gameweeks (Tuesday start), so every row of a match shares a block. Intervals on fewer than 30 bets are shown but not counted.

## Headline

- Fit A: 1176 slice x period x line intervals tested; 554 exclude zero vs about 58.8 expected by chance alone (5%). Plus lines with the interval above zero: 208; minus lines below zero: 322.
- Fit B: 1176 slice x period x line intervals tested; 553 exclude zero vs about 58.8 expected by chance alone (5%). Plus lines with the interval above zero: 210; minus lines below zero: 320.

Slices overlap (all, halves, nested lines, both sides of a match), so these tests are strongly correlated; the 5% chance figure assumes independent tests and is only a rough yardstick.
Both fits reproduce the 1X2 exactly, so returns on the +/-0.5 lines measure bias in Pinnacle's proportional margin-free close, not fit error; the wider lines add the matrix's own tail error.
A positive plus-line return means the matrix fair odds are too long there, which UNDERSTATES a derived edge; a negative minus-line return means it OVERSTATES one. That is why the v27 derived reference is limited to plus lines.
