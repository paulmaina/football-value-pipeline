Practical workflow:
======================================================================================================================
1. Run the prediction command and formatter.
2. Push forecasts so GitHub can archive them before kickoff.
3. The local scheduled task collects near-close quotes.
4. Push those collected files later.
5. GitHub verifies results, grades experiments and updates reports.


Reconcile:
=======================================================================================================================
git status
git add .
git commit -m "Update local forecasts and collected data"
git pull --rebase origin main
git push origin main

If there are conflicts:
1. Run git status to identify the affected files.
2. Resolve each conflict, removing the <<<<<<<, ======= and >>>>>>> markers.
3. Continue:
  >git add .
  >git rebase --continue
